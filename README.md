# VTPlayer Lab

Experimental native iOS 26 video playback using Apple's public VideoToolbox frame processing APIs.

- Original, 2× frame interpolation (FG), super resolution (SR), and sequential FG + SR.
- Built-in 360p / 480p / 720p 24fps synthetic moving test patterns generated by FFmpeg during CI; no download required at runtime.
- Local SDR MP4/MOV selection, input at most 1280×720; SR selects the highest supported scale that fits within 1920×1080.
- Reports API support, supported SR factors, submitted FPS, generated frames, late frames, dropped submissions, processing time and thermal state.

## Install

Open Actions → Build IPA → successful run → VTPlayer-IPA artifact. Extract the outer ZIP, import VTPlayer.ipa into LiveContainer. The IPA is unsigned. Actual LiveContainer compatibility and A15 support are unverified.

## Test

Choose a sample and a mode, press Play. Stop before switching mode. Start with Original, then FG, SR, and FG + SR at each resolution. An unsupported configuration or processing failure is reported explicitly. Submitted FPS does not measure physical display refresh. Late frames are counted, not skipped; overloaded playback can lag. This prototype is silent, lacks seeking and subtitles, and does not handle HDR or rotated video.
